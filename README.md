# Aura - Local AI Desktop Companion

> Developed by Atlas Labs

Aura is a next-generation desktop companion app designed to bring lightning-fast, 100% private artificial intelligence directly to your PC. Running locally through lightweight integrations like Ollama, Aura floats discreetly on your desktop as an adaptive widget that expands seamlessly on hover.

---

## Key Features

* **Privacy-First Local AI:** Operates entirely on your hardware with zero data leaks, supporting models like Llama and DeepSeek via Ollama.
* **Smart Desktop Widget:** An ultra-minimalist, transparent floating pill featuring 4-way adaptive anchoring that expands seamlessly into a smart chat panel.
* **Real-Time Screen & File Intelligence:** Capable of reading local files and analyzing your screen in real time to assist with coding, workflows, and gaming.
* **Full Control Center Dashboard:** A dedicated companion interface to customize themes, transparency, AI personality, local resource monitoring (CPU/GPU/RAM), and secure subscription settings.

---

## Tech Stack

* **Framework:** Electron & React 19
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **AI Integration:** Ollama (Local LLMs)
